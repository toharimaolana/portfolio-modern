# LinkAja Kas — Shared Fund UX Concept
Author: **Mohamad Tohari Maolana**

---

## The Problem

Managing collective group finances (such as office funds, community sports groups, or family pools) is often a fragmented task. Organizers are forced to juggle WhatsApp threads, manual spreadsheets, and bank transfers, leading to administrative overhead, lack of payment transparency, and awkward conversations. LinkAja users needed an integrated, in-app cash-pooling feature.

## My Role

**UI/UX Designer** — Designed the end-to-end user-centered financial workflow in Figma, established the visual information architecture, built reusable component libraries, and designed interactive prototypes.

## The Process

1. **User Research:** Interviewed group administrators to map out typical steps for managing recurring contributions, documenting common pain points (forgetting payments, tracking transaction histories).
2. **Information Architecture:** Created dashboard layouts that display active cash groups, total pool balance, payment timelines, and individual member statuses at a single glance.
3. **Figma Component Design:** Engineered a comprehensive mobile design system matching LinkAja's native branding guidelines (high-visibility red, neutral darks, and scannable grids).
4. **Friction Minimization:** Added micro-interaction features like automated transaction notices, digital payment indicators, and quick-reminders to nudge outstanding members smoothly.

## Key Design Approach & Features

- **User-Centered Cash Workflows:** Streamlined setup forms that allow group admins to create community cash groups, set custom targets, and define weekly/monthly dues.
- **Visual Transaction Transparency:** Clean transaction timelines showing incoming payments, outgoing expenditures, and attached digital receipts.
- **LinkAja Design System Scaling:** Developed modular buttons, list-cards, and status badges in Figma to ensure consistent layout across the product ecosystem.
- **Contextual Reminders:** Designed non-intrusive payment nudges and automated reminders to simplify collection follow-ups.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Prototyping & Layout | Figma |
| Design Tokens | LinkAja Brand Guideline Assets |
| Target Viewport | Mobile (iOS/Android Native UI) |
| Architecture | Information Hierarchy & Workflow Auditing |

## Design Impact & Learnings

- Conceptualized a cohesive, intuitive workflow that eliminates manual bookkeeping, extending the core financial services value of the LinkAja ecosystem.
- Deepened understanding of **mobile financial UI patterns**, balancing security indicators with high usability.
- Learned the discipline of designing **scalable UI component libraries** that fit existing brand guidelines.
