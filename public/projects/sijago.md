# SiJago Course — Gamified Coding Mobile UI
Author: **Mohamad Tohari Maolana**

---

## The Problem

Learning programming and computer science can be intimidating for beginners, often leading to rapid drop-offs due to dry theory, complex setup instructions, and a lack of immediate visual feedback. To keep students motivated, an e-learning platform needs a mobile-first UI that combines bite-sized lessons, interactive code exercises, and competitive community mechanics in a gamified layout.

## My Role

**UI/UX Designer** — Conducted competitor research, designed the adaptive dashboard modules, structured the lesson step indicator components, and built the mobile design library in Figma.

## The Process

1. **Gamification Analysis:** Studied popular gamified learning applications (such as Duolingo and SoloLearn) to adapt their progress mechanics for computer science subjects.
2. **Mobile Layout Flow:** Designed a 375x812px mobile framework featuring bottom navigation bars for quick thumb access to courses, coding challenges, leaderboards, and user stats.
3. **Structured Lesson Path:** Created a visual roadmap indicating completed, active, and locked programming modules to encourage students to continue learning.
4. **Figma Auto-Layout Setup:** Developed reusable component cards for interactive coding quizzes, success/error feedback modals, and profile badge showcases.

## Key Design Features

- **Gamified Roadmap Layout:** An interactive study timeline presenting programming courses (Python, JavaScript, SQL) as a sequence of gamified steps.
- **Bite-Sized Coding Challenges:** Screen layouts designed to present multiple-choice syntax quizzes and drag-and-drop code blocks with instant visual feedback.
- **Student Leaderboards:** Real-time ranking boards displaying study XP, active daily streaks, and community achievements to drive healthy competition.
- **Lightweight Figma Component Library:** High-contrast buttons, status indicators, and progress bars optimized for clean developer handoff.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Design Software | Figma |
| Display Resolution | Mobile UI (375x812px viewport) |
| Layout System | Figma Auto-Layout Components |
| Target Audience | Beginner Programming Students |

## Design Impact & Learnings

- Designed an engaging mobile-first learning UI concept, proving that gamified design elements can make computer science education accessible.
- Gained experience **balancing gamified UI widgets** with clear educational layout structures, avoiding visual clutter on small screens.
- Strengthened capabilities in **designing for touch viewports**, ensuring buttons and interactive quiz targets are sized correctly for effortless navigation.
