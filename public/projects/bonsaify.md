# Bonsaify Store — Premium Botanical E-Commerce UI
Author: **Mohamad Tohari Maolana**

---

## The Problem

Premium botanical brands often struggle to convey luxury and value on traditional e-commerce templates, which are cluttered and transactional. To justify premium pricing for products like curated Bonsai trees, the digital interface needs to balance high-end brand storytelling with smooth checkout paths, conveying a peaceful "Zen" shopping experience.

## My Role

**UI/UX Designer** — Crafted the visual identity, established the whitespace and typography rules, designed the storefront grid layouts, and built responsive component states in Figma.

## The Process

1. **Aesthetic Research:** Explored Japanese minimalist layouts, prioritizing breathing room, high-contrast imagery, and natural earth-tone colors.
2. **Typography Selection:** Paired elegant serif display headers (for botanical names) with clean sans-serif bodies (for pricing and care stats) to build editorial balance.
3. **E-Commerce Conversion Flow:** Positioned CTA triggers ("Buy Now", "Explore Collection") in a way that feels organic and non-intrusive.
4. **Figma Responsive Design:** Engineered modular auto-layout card elements to scale seamlessly from widescreen monitors to phone viewports.

## Key Design Approach & Features

- **Zen Visual Architecture:** Generous whitespace and a warm, natural color palette that highlights curated bonsai photography.
- **Editorial Brand Storytelling:** High-contrast serif headlines combined with minimal specifications grids to build premium value.
- **Organic CTA Placement:** Elegant, soft-touch conversion buttons placed naturally along the visual scroll path.
- **Modular Component Grid:** A flexible Figma card library that preserves margins and spacing across screen sizes.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Design Software | Figma |
| Visual Scale | Warm earth-tones (sage green, sand, off-white) |
| Grid Structure | 12-Column Desktop Grid & 4-Column Mobile Grid |
| Key Typographies | Elegant Serif Display + Clean Sans-Serif Body |

## Design Impact & Learnings

- Conceptualized a botanical storefront UI, successfully elevating niche retail into a high-end luxury shopping experience.
- Learned the balance of **whitespace management**, showing that breathing room in a layout directly impacts perceived product value.
- Refined the creation of **clean auto-layout constraints in Figma** to ensure developer handoff is painless.
