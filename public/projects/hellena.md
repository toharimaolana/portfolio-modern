# Hellena — B2B Health Tech Landing Page
Author: **Mohamad Tohari Maolana**

---

## The Problem

Enterprise healthcare technologies are complex, and marketing landing pages often overwhelm business decision-makers with dense jargon, leading to low demo conversions. B2B healthcare brands need a trust-centric web interface that translates complex tech architectures into a clear value proposition, encouraging clients to explore solutions and schedule demos.

## My Role

**UI/UX Designer** — Responsible for information hierarchy design, creating scannable visual modules, building B2B conversion pathways, and designing a responsive layout grid system in Figma.

## The Process

1. **Hierarchy Formulation:** Analyzed enterprise landing pages to identify sections that build maximum trust (clinical stats, partner logos, solution pillars).
2. **Conversion Path Setup:** Placed primary call-to-actions ("Schedule Demo", "Explore Solutions") at high-intent visual locations.
3. **Figma Auto-Layout System:** Built responsive grid systems and auto-layout card components to fit different desktop and mobile screen widths.
4. **Data Visualization:** Translated dense health tech infrastructure workflows into scannable feature diagrams.

## Key Design Approach & Features

- **Trust-Centric Spatial Design:** Clean layouts utilizing generous white space and compliant contrast ratios to establish enterprise authority.
- **Enterprise Conversion Architecture:** Clear value-proposition sections with scannable feature cards prompting B2B visitors to sign up for demos.
- **Responsive Figma System:** Modular card assets and layouts built for seamless screen responsiveness.
- **Workflow Simplification:** Visual blocks that break down complex digital health tech processes into simple diagrams.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Design Software | Figma |
| Design System | Auto-Layout Components & Global Type Styles |
| Typography | High-legibility sans-serif scales |
| Contrast Target | WCAG-compliant enterprise color palette |

## Design Impact & Learnings

- Designed an enterprise-grade landing page interface, successfully blending healthcare reliability with modern B2B tech aesthetics.
- Mastered the layout formatting needed to make complex B2B technologies digestible and engaging.
- Strengthened capabilities in building **Figma design systems** that speed up frontend handoff processes.
