# GShop — Practical Pocket
Author: **Mohamad Tohari Maolana**

---

## Project Overview

**Practical Pocket** is an innovative and discrete envelope design created to help women store and discard used sanitary pads with ease. It provides an odor-free, highly hygienic, and practical solution when traveling or in locations without accessible disposal facilities.

I designed and developed a high-converting, single-product landing page on Framer to introduce the product features, build trust, and drive promotional conversions.

## My Role

**Framer Developer** — Translated visual wireframes and copy guidelines into a fully responsive, pixel-perfect promotional page, configuring smooth hover triggers and mobile navigation.

## Key Features

- **Discreet Visual Tour:** High-contrast product presentation highlights the odor-blocking materials and envelope styling.
- **Hygienic Step-by-Step Guide:** Clean, visual user guidelines showing folding, storing, and disposal instructions.
- **High-Velocity CTAs:** Mobile-friendly buy buttons optimized for swift user conversions.

## Technical Stack

- **Platform:** Framer
- **Interactions:** Scroll animations & micro-transitions
- **Live URL:** [gshop.framer.website](https://gshop.framer.website/)
