# Course Online — Collaborative Learning Mobile UI
Author: **Mohamad Tohari Maolana**

---

## The Problem

Peer-to-peer study groups are a vital part of computer science education, but students often struggle to coordinate study sessions, share study resources, and maintain learning consistency due to fragmented tools. The Informatics Engineering Student Association (HIMTIF) needed a unified mobile-first portal to digitize and encourage collaborative peer-to-peer learning.

## My Role

**UI/UX Designer** — Conducted user research, mapped student onboarding pathways, structured the app navigation systems, and built a consistent mobile design system in Figma.

## The Process

1. **User Onboarding Mapping:** Designed an adaptive onboarding flow allowing students to choose self-study pathways, join active study groups, or download learning materials.
2. **Navigation Design:** Established a simplified 4-tab mobile layout (Home, Explore, Leaderboard, Profile) to optimize thumb reachability on 375x812px viewports.
3. **Gamification Strategy:** Incorporated community indicators (leaderboards, study badges, forum points) to increase student engagement and drive study habits.
4. **Figma Auto-Layout System:** Built high-contrast component libraries in Figma, ensuring visual consistency across buttons, course cards, and chat bubbles.

## Key Highlights & Design Approach

- **Adaptive Study Onboarding:** Tailors the main home dashboard based on the student's selected study track (independent learning, peer tutoring, or team projects).
- **Informatics Study Hub:** Clean information architecture displaying programming topics, syllabus steps, and live coding exercises.
- **Interactive Peer Community:** Visual designs for study chats, forum discussion threads, and student score leaderboards.
- **Mobile-First Components:** Accessible buttons, text layers, and card containers built strictly for touch-screen targets.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Design Software | Figma |
| Display Spec | Mobile viewport (375x812px) |
| UI Framework | Auto-Layout Components |
| Target Audience | Informatics Engineering Students |

## Design Impact & Learnings

- Delivered a comprehensive mobile educational UI concept, transforming passive reading resources into a collaborative learning environment.
- Sharpened skills in **mobile information architecture**, keeping user screens scannable and reducing cognitive load during intensive study cycles.
- Strengthened capabilities in **designing gamified user behaviors** to drive tech-community participation.
