# PetaPetu — Immersive Travel Discovery UI
Author: **Mohamad Tohari Maolana**

---

## The Problem

Travel booking websites often look like crowded listing directories, which fails to inspire users and leads to rapid drop-offs. Tourism and agency brands need a landing page UI that inspires users through high-impact photography, social proof metrics, and clear destination discovery paths to guide travelers from research to booking action.

## My Role

**UI/UX Designer** — Responsible for the layout design, crafting the hero typography, designing card components, and organizing structured feedback blocks in Figma.

## The Process

1. **Hero Concept Design:** Formulated a visual layout featuring a tropical backdrop, clean headers, and an elevated statistics display to build immediate brand trust.
2. **Destination Card Prototyping:** Designed grids presenting vacation hotspots with clean typography overlays and clear exploration buttons.
3. **Partner Placement:** Structured a monochromatic partner bar to display trusted airline and payment brands without cluttering the screen.
4. **Testimonial Layout:** Designed testimonial cards featuring user avatars, star-rating indicators, and text bubbles.

## Key Design Approach & Features

- **High-Impact Travel Hero:** Expansive hero backdrop with clean navigation and a floating stats bar (72K+ Members, 20 Countries, 1K+ Hotels).
- **Curated Destination Cards:** Card grid layout highlighting travel locations with dark overlay contrasts and "View Details" triggers.
- **Trusted Partner Bar:** Clean partner banner layout displaying monochromatic corporate logos (ANA, Disney, Visa) to build traveler confidence.
- **Testimonial Scannability:** Clean user feedback layouts featuring star ratings and student/traveler descriptions.

## Design Tools & Specs

| Layer | Tools & Guidelines |
|:------|:-------------------|
| Design Software | Figma |
| Grid System | Standard Responsive Container Grids |
| UI Tokens | High-contrast overlays & tropical accents |
| Viewport | Desktop Web Interface Layout |

## Design Impact & Learnings

- Deployed a modern travel landing page UI, successfully guiding visitors from travel inspiration to booking workflows.
- Learned the value of **social proof layouts**, showing how visible metrics and partner logos directly build user trust.
- Strengthened capabilities in **designing high-contrast visual cards** that remain readable over complex photographic backdrops.
