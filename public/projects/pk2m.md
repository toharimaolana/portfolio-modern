# PK2M — Civic & Multicultural Learning Platform
Author: **Mohamad Tohari Maolana**

---

## The Problem

Traditional university civic education is often confined to static PDF modules and slide presentations, limiting students' engagement with interactive, real-world public policy issues. Pancasila and Civic Education (PPKn) academic teams needed an online hub (PK2M) where students could access guidebooks, analyze public issues, and collaborate on multicultural citizenship projects from any device.

## My Role

**Front-End Developer** — Developed the semantic frontend, styled the platform using Tailwind CSS, structured the learning repository hierarchy, and optimized cross-browser viewing layouts.

## The Process

1. **Information Design:** Worked alongside academic coordinators to translate civic worksheets and project rubrics into scannability-optimized web layouts.
2. **Slicing UI:** Used HTML5 semantic elements and Tailwind CSS utilities to code clean, high-contrast dashboards.
3. **Collaboration Features:** Engineered responsive project submission pipelines and group list grids to host collaborative student assignments.
4. **Performance Auditing:** Ensured fast initial page loading speeds and uniform performance on low-end mobile devices and university lab PCs.

## Key Highlights & Architecture

- **Public-Issue Competency Engine:** Structured layout widgets that guide students step-by-step through analyzing public policy, applying Pancasila core values, and submitting group projects.
- **Accessible Digital Library:** A streamlined digital repository listing multicultural civic guidebooks, project rubrics, and educational downloads.
- **High-Scannability Layouts:** Designed clean typography hierarchies and navigation cards to minimize cognitive load during academic study.
- **Cross-Browser Optimization:** Responsive, mobile-first CSS architecture ensuring stable rendering and low data consumption.

- Deployed a scalable academic platform (hosted at `fiernamasmultikultural.com`) that successfully digitalized civic project management for future educators.
- Solidified understanding of **utility-first styling workflows** with Tailwind CSS, maintaining precise spacing rules.
- Gained experience matching **academic content models** with accessible, user-friendly frontend interfaces.
